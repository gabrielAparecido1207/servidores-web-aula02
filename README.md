## Resumo da aula
Essa aula foi sobre servidores e ambientes web. Vimos o que é um servidor web (a junção de
hardware e software que recebe requisições e devolve páginas, arquivos ou serviços), os
principais tipos de servidor (HTTP, FTP, aplicação e streaming), a arquitetura por trás disso
e a diferença entre ambiente local/remoto e desenvolvimento/produção. Também revisamos
versionamento com Git e GitHub.

## O que aprendi sobre servidores web
Aprendi que servidor web não é só a máquina física, é a combinação de hardware e software
trabalhando juntos pra processar pedidos e devolver respostas em poucos milissegundos. Também
ficou mais claro que existem tipos diferentes de servidor pra cada necessidade (um blog não
precisa da mesma estrutura que um banco, por exemplo) e que separar ambiente de desenvolvimento
do de produção evita que um erro de teste afete quem já está usando o sistema de verdade.
